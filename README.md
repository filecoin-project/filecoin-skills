# filecoin-skills

A suite of Filecoin skills for agents.

## Skills

| Skill | What it does |
|---|---|
| [`publish`](./skills/publish/) | Publish what your agent just made: one prompt from any local file or folder to a content-addressed, verified, stored browser link. |

## Install

```bash
npx skills add filecoin-project/filecoin-skills --skill publish
```

Each skill's own README covers its prerequisites and first-time setup.
